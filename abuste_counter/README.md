# ابوسطه‌شمار

اپلیکیشن آفلاین اندروید برای شمارش امتیاز بازی «ابوسطه»، با Python + Kivy/KivyMD.

## ساختار پروژه
```
abuste_counter/
├── main.py                    # نقطه ورود، ScreenManager، اتصال دیتابیس
├── screens/
│   ├── home_screen.py         # صفحه اصلی
│   ├── new_game_screen.py     # شروع بازی جدید (نام گروه‌ها)
│   ├── game_screen.py         # صفحه اصلی بازی (امتیاز زنده، ثبت دور، Undo)
│   ├── round_screen.py        # ثبت دور جدید + پاپ‌آپ تأیید
│   ├── history_screen.py      # تاریخچه دورهای یک بازی (جاری یا آرشیو)
│   ├── games_history_screen.py# لیست بازی‌های پایان‌یافته قبلی
│   └── settings_screen.py     # تنظیمات
├── game/
│   ├── rules.py                # AbusteRules: منطق امتیازدهی (مستقل از UI)
│   └── game_engine.py          # GameEngine: مدیریت وضعیت بازی جاری
├── database/
│   └── database.py             # SQLite: games / rounds / settings
├── models/
│   ├── game.py
│   └── round.py
├── utils/
│   └── persian_text.py         # شکل‌دهی صحیح متن فارسی برای Kivy
├── assets/fonts/                # فونت فارسی را اینجا اضافه کنید
├── buildozer.spec
└── requirements.txt
```

## قوانین امتیازدهی (تأییدشده)
- بازه خواندن: ۵ تا ۹
- خواندن ۵ تا ۹: موفق → + عدد خوانده‌شده برای گروه خواننده
- خواندن ۵ تا ۹: ناموفق → گروه خواننده بدون تغییر؛ گروه حریف + (۲ × عدد خوانده‌شده)
- کوت: امتیاز همان دور دو برابر می‌شود
- هدف بازی: ۶۲ امتیاز

## تست روی دسکتاپ
1. یک فونت فارسی (پیشنهاد: Vazirmatn) را در مسیر زیر قرار دهید:
   `assets/fonts/Vazirmatn-Regular.ttf`
2. نصب وابستگی‌ها:
   ```
   pip install -r requirements.txt
   ```
3. اجرا:
   ```
   python main.py
   ```

مسیر تست پیشنهادی: صفحه اصلی → شروع بازی جدید → نام‌ها → چند دور با
حالت‌های مختلف (موفق/ناموفق/کف/کوت) ثبت کن → لغو آخرین دور را امتحان
کن → تاریخچه دورها را ببین → برنامه را ببند و دوباره باز کن (باید
دکمه «ادامه بازی» فعال باشد و امتیاز دقیقاً همان‌جا که رها کرده بودی
ادامه یابد) → به ۶۲ برسان و بنر برنده را ببین → از تنظیمات یک نام
گروه را تغییر بده، تأیید ثبت دور را غیرفعال کن، و تاریخچه را پاک کن.

## Build اندروید (فاز ۱۰)
> نکته: Build واقعی APK نیاز به Linux با buildozer و اتصال اینترنت
> (برای دانلود Android SDK/NDK) دارد و در این محیط توسعه (بدون
> دسترسی به شبکه) قابل انجام نیست. مراحل زیر را روی سیستم خودت اجرا کن.

روی یک سیستم لینوکس (یا WSL):
```bash
pip install buildozer cython
sudo apt install -y git zip unzip openjdk-17-jdk python3-pip autoconf \
    libtool pkg-config zlib1g-dev libncurses5-dev libncursesw5-dev \
    libtinfo5 cmake libffi-dev libssl-dev

cd abuste_counter
buildozer android debug
```
اولین Build ممکن است طولانی باشد (دانلود خودکار Android SDK/NDK).
فایل خروجی در مسیر زیر ساخته می‌شود:
```
bin/abustecounter-0.1-arm64-v8a_armeabi-v7a-debug.apk
```

### نصب روی گوشی
1. فایل APK را به گوشی منتقل کن (کابل، بلوتوث، یا لینک ابری).
2. در تنظیمات گوشی «نصب از منابع ناشناس» را برای File Manager فعال کن.
3. روی فایل APK ضربه بزن و نصب کن.
4. برای نصب مستقیم از طریق buildozer (وقتی گوشی با USB وصل و
   Debugging فعال است):
   ```
   buildozer android debug deploy run
   ```
